# Project: Agency SEO Ranker

This project contains an SEO audit skill for AI-generated websites.

## When to use

When the user asks about SEO, rankings, site audits, or Google visibility for any web project — particularly sites generated by AI tools.

## Workflow

1. Read [SKILL.md](../SKILL.md) once. It contains the complete 28-item checklist organized into 7 phases.
2. Run `python scripts/seo_audit.py <target>` for an automated baseline scorecard.
3. Audit each phase in order. Do not skip Phase 1 (crawlability).
4. Score every item 0–3 (max 84 points).
4. Output:
   - Scorecard table
   - Prioritized fix list
   - Before/after evidence where possible
   - 30-day improvement plan

## Key resources

- `SKILL.md` — full checklist with descriptions, AI traps, and tool tips
- `docs/usage.md` — quick-win triage and red-flag patterns
- `examples/audit-template.md` — ready-to-use report template
