## Agency SEO Ranker (SEO audit mode)

When auditing or improving the search visibility of any website — especially one generated by AI — follow the `agency-seo-ranker` skill defined in [SKILL.md](./SKILL.md).

Run `python scripts/seo_audit.py <target>` and the 28-item checklist across 7 phases in strict order. Score each item 0–3 (max 84). Return:
1. Scorecard table
2. Prioritized fix list (highest impact first)
3. Before/after evidence
4. 30-day improvement plan

Read SKILL.md once per session. Never skip Phase 1 (crawlability).
